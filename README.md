# saqr-packs

Audio packs for **Saqr** («صقر», German and English grammar), an app by Ahmad Yaghi.

This repository holds **no code** and no keys. The folders `<pack>/` (`de-A2`, `de-B1`, … `en-C1`) each hold one `files.json` (clip list with SHA-1) and the clips as `.m4a`. They are served by GitHub Pages at `https://hudhud-learn.github.io/saqr-packs/<pack>/…`. The app downloads a pack only when the learner asks for it.
